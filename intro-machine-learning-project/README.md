# Introduction to Machine Learning Project

Repository ini berisi implementasi dasar pengantar Machine Learning, mencakup data preparation, model training (Supervised Learning), dan evaluasi performa model.
Terinspirasi dari kuliah umum oleh **Dr. Taniza Tajudin** (Universiti Teknologi MARA / UiTM Cawangan Kedah, Malaysia) dalam *Informatics Practitioner Lecture Series*.

## 📚 Modul Proyek
- **`data_preprocessing.py`**: Pembuatan dan pembersihan dataset sintetis untuk pembelajaran mesin.
- **`train_model.py`**: Pelatihan model klasifikasi menggunakan Scikit-Learn.
- **`predict.py`**: Melakukan pengujian/prediksi dengan data baru.

## 🚀 Cara Menjalankan
1. Install dependensi: `pip install -r requirements.txt`
2. Jalankan preprocessing: `python data_preprocessing.py`
3. Latih model: `python train_model.py`
