## 📊 Pemahaman & Implementasi Algoritma

Dalam laporan tugas ini, dilakukan penelaahan terhadap enam algoritma *Supervised Learning* berikut:

| Algoritma | Jenis Model | Kegunaan & Mekanisme Kerja |
| :--- | :--- | :--- |
| **K-Nearest Neighbors (KNN)** | Klasifikasi | Menentukan kelas objek berdasarkan konsensus mayoritas dari $k$-tetangga paling dekat. |
| **Linear Regression** | Regresi | Memprediksi variabel kontinu menggunakan garis tren hubungan linear. |
| **Ridge Regression** | Regresi | Regresi linear yang dilengkapi regularisasi L2 guna menstabilkan koefisien dan mengendalikan *overfitting*. |
| **Naive Bayes** | Klasifikasi | Mengklasifikasikan data berbasis probabilitas Teorema Bayes dengan asumsi antarfitur saling independen. |
| **Decision Tree** | Klasifikasi / Regresi | Memetakan keputusan berdasarkan struktur aturan percabangan hierarkis. |
| **Random Forest** | Ensemble | Menggabungkan prediksi dari banyak *Decision Tree* untuk hasil yang lebih konsisten dan akurat. |
